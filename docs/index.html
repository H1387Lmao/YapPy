GETTING STARTED

Installation

Install YapPy from PyPI, then create a small bot application to get started.

Requirements

  • Python 3.14 or newer for the currently published package.
  • A Yapper bot token from your developer settings.
  • Network access to the Yapper API.

Install from PyPI

Run this command in your environment:

shell
python -m pip install python-yappy

Set your token

Keep your bot token private. An environment variable is preferable to placing it directly in source code.

bash / zsh
export YAPPER_BOT_TOKEN='your-token-here'
YOUR FIRST BOT

Quick start

Create an application, listen for messages, and register a command.

bot.py
import os
from yappy import App

bot = App(verbose=True)

@bot.event("message")
async def on_message(ctx):
    if ctx.is_bot:
        return
    await ctx.reply("Hi!")

@bot.command(name="ping", description="Replies with Pong!")
async def ping(ctx):
    await ctx.reply("Pong!")

bot.run(os.getenv("YAPPER_BOT_TOKEN"))

Run the bot

shell
python bot.py

This example follows the current public project interface. Confirm event names, callback arguments, and command behavior against the version installed in your environment.
